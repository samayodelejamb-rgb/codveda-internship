# Personal Portfolio Website

A modern and responsive personal portfolio website created to showcase my skills, projects, experience, and background as a Frontend Developer & UI/UX Designer.

## Technologies

* HTML5
* CSS3
* JavaScript
* Responsive design with CSS media queries
* Figma

## Project

The portfolio website includes a navigation bar, hero section, about section, skills section, services, projects showcase, and contact section. The website is designed with a modern interface and responsive layout to provide a smooth experience across desktop, tablet, and mobile screen sizes.

It serves as a central platform to showcase my frontend development projects, technical skills, and experience while providing visitors with an easy way to learn more about me and get in touch.
